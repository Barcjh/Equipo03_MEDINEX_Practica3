# Equipo03_MEDINEX_Practica3

Prototipo funcional de frontend para el sistema de gestión de citas médicas (Caso Maestro: MEDINEX).

## Descripción del prototipo
Este proyecto es una aplicación web frontend (HTML, CSS y JavaScript vanilla) que simula la gestión de citas para una red de clínicas. Implementa 5 pantallas con navegación real, datos simulados (sin información clínica real) y validaciones de reglas de negocio como el traslape de horarios y la ventana de reprogramación.

## Tecnología utilizada
* HTML5
* CSS3
* JavaScript (Vanilla)

## Instrucciones de ejecución local
1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge).
3. No se requiere servidor backend ni instalación de dependencias.

## Uso de Inteligencia Artificial
La estructura visual (HTML y CSS) y la lógica base de JavaScript fueron generadas con el apoyo de asistentes de IA (Claude/ChatGPT/Figma Make). El equipo revisó, corrigió y adaptó manualmente la lógica de negocio en el archivo `store.js` para asegurar el cumplimiento de las reglas del SRS (RN-05, RN-06, RN-07, RN-11).
